Implements the hands in the Marvellous as [collated by bourbon_munch](https://www.reddit.com/r/fallenlondon/comments/1stq33d/master_sparks_presents_the_comprehensive_rules_of/), and [the FLatro deck skin by violant-apologia](https://violant-apologia.tumblr.com/post/766255491109289984/flatro-full-deck). Requires [Lovely](https://github.com/ethangreen-dev/lovely-injector) and [Steamodded](https://github.com/Steamodded/smods).

Playing The Marvellous by normal means requires first clearing any other deck on Gold Stake or higher. If you wish to skip this requirement, might I suggest [re:Unlock All](https://github.com/wingedcatgirl/re-Unlock-All)?
